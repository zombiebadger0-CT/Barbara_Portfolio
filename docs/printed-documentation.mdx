# Printed Documentation

These manuals and posters, examples of documentation formatted for print, were developed for Propel, a large-scale automated clinical specimen processing system manufactured by Protedyne for Labcorp. As Senior Technical Trainer and Writer, I developed the documentation through hands-on operation of the system, independent research of its functionality and error conditions, review of engineering drawings and design specifications, and collaboration with hardware, electrical, and software engineers.

Although the documentation was also published as online help, Labcorp required printed manuals at each installation. In practice, the printed guides remained essential reference tools for laboratory staff, particularly when troubleshooting equipment or resolving issues in the middle of an operation. The system was deployed at nine locations, each with a unique physical configuration and processing capacity. I used a single-sourcing approach to manage shared content while maintaining site-specific variations through reusable snippets, producing tailored documentation for each installation while ensuring consistency across all nine sites.
